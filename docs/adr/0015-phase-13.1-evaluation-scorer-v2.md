# ADR 0015: Phase 13.1 Task Contracts and Scorer V2

- Status: Accepted and verified
- Date: 2026-09-02

## Context

Phase 13 used fixed expected traces, strict argument equality, one final Policy decision, Boolean
confirmation/recovery fields, and Policy-derived execution expectation. Saved results showed that
these shortcuts could attribute evaluator and infrastructure behavior to the Agent.

## Decision

Preserve V1 and add `DriveGuard-Eval-v2.0.0` Task Contracts. Score required/conditional/forbidden
Tools, typed arguments, action-level Policy, ordered confirmation system events, execution channels,
recovery contracts, safety enforcement, and final-response state claims independently. Attribute
failures to Agent, evaluation, or infrastructure. Core scoring remains deterministic.

Case concurrency is allowed only with independent Runtime/Simulator state. Quality defaults to 4;
latency defaults to 1. Benchmark retries may handle declared infrastructure errors only and cannot
consume intentionally injected DriveGuard faults.

CAR-bench official rewards remain authoritative and unchanged, with an additional orthogonal trial
validity classification. Native and CAR-bench scores remain separate.

## Consequences

Historical V1-only observations remain explicitly `NOT_SCORABLE`. The completed 600-case live V2
quality trace supplies the missing dimensions and supports exact V1/V2 transition reporting; the
separate 600-case concurrency-1 run supplies serial latency. Deterministic 100% results validate
plumbing only. Evaluation-derived trace fields may be deterministically normalized during offline
rescore when the raw evidence is sufficient, and the report records the scorer version and rescore
timestamp. Phase 13.2 may use this frozen baseline but is outside this ADR and was not started.
